The problem

Two truths that put you in a box.

Software engineers fixed this class of problem for passwords with hashing and for photos with on-device processing. Medicine never got that fix — until now.

The pill that silently fails

Clopidogrel (Plavix) is one of the most prescribed drugs on Earth, given after stents to prevent deadly clots. But up to 1 in 3 people carry a gene variant that stops the body from activating it — a missed dose in disguise. Regulators and CPIC guidelines say: check the patient's genetics before prescribing. Almost nobody does, because the check has been too invasive.

The file you can never take back

To check, an AI assistant would ask for your raw DNA export (23andMe, AncestryDNA, VCF). That file is the ultimate identity leak — you can change a leaked password in a minute, but you can never change your genome, and it links to your relatives too. Uploading it to any server or model context is a privacy decision that lasts forever.

How it works

Three steps. Zero exposure.

GeneVault is a WebMCP server that lives inside your browser tab. The AI talks to it; it talks to your local data; the only thing that crosses the boundary is a cryptographic verdict.

STEP 1

Your DNA stays in the vault

Drop your raw 23andMe / AncestryDNA / VCF file into the page. It is parsed line-by-line in local memory — 600,000+ positions scanned in about a second. Nothing is uploaded; there is no server to upload to.

client-side · no upload
STEP 2

The AI asks through WebMCP

"Is clopidogrel safe for this patient?" The agent discovers GeneVault's tools via document.modelContext.registerTool() and calls them like any API — but the tools run on your machine, gated by your consent.

12 registered tools · you approve each release
STEP 3

It answers with a proof

The browser generates a real Groth16 zero-knowledge proof (bn128 curve, ~2s). The AI learns exactly one bit of truth — "unsafe for this patient" — verified by mathematics, with your actual genotype sealed inside the circuit.

Groth16 · replay-protected · on-chain ready

No biology degree needed — think of a nightclub bouncer

You can prove you're old enough to enter without showing the bouncer your birth date — that's the classic zero-knowledge idea. GeneVault does the same for medicine: the AI asks "is this drug safe for this person?" and gets back a mathematically-checkable YES/NO. It never sees your birth date (your genotype), your ID (your file), or even your name. And unlike a bouncer, this one is a Groth16 verifier on the bn128 curve — if it says VALID, it is cryptographically certain.

Real, verified engineering

  • Groth16 over bn128 via snarkjs — 8,845 constraints, 32/32 end-to-end Node tests pass
  • Merkle membership (Poseidon, depth 4), EdDSA issuer signature and nullifier all checked inside the circuit
  • Replay protection: each proof has a single-use nullifier; forgery attempts fail at witness generation (try the in-app Forgery Audit)
  • Real WebMCP: 12 tools on document.modelContext, verified via getTools() — the same API ChatGPT's browser and Chrome consume
  • Real structures: live RCSB PDB loads (4GQS, 2F9Q…), real CPIC Level A guideline content

Honestly labeled demo boundaries

  • Synthetic patient files ship with the repo — bring your own raw DNA export to prove it on real data, fully offline
  • Curator / issuer / prover run in one browser for the demo; production splits them across lab, registry and patient
  • SNP-array scope: CYP2D6 copy-number, HLA typing and UGT1A1 repeats are out of reach for consumer chips — the UI says so instead of faking it
  • Not medical advice: a privacy-technology demonstration, clearly labeled in the app
